# VIARENT — A sua viagem começa aqui

## 1. Sobre o projeto

A **VIARENT** é um website fictício de aluguer de automóveis, desenvolvido no âmbito da unidade curricular de **Aplicações Web**, da Licenciatura em Informática de Gestão.

O objetivo do projeto é permitir aos utilizadores consultar viaturas disponíveis, conhecer as suas características e preços e efetuar pedidos de reserva de forma simples, rápida e intuitiva.

## 3. Estrutura do repositório

## 4. Esquemas do website

O projeto inclui esquemas de duas páginas do website, em versões mobile e desktop:

- Página inicial — Mobile
- Página inicial — Desktop
- Viaturas — Mobile
- Viaturas — Desktop

## 5. Referências

Foram consultados os websites da Sixt, Europcar, Hertz e Avis como referências para a organização das páginas, apresentação das viaturas e funcionalidades de reserva.
